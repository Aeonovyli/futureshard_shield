# futureshard_shield
This mod adds an nelsylite powered kill field for destroying large clusters of mobs. This mod is compatible with VoxeLibre.

The field is invisible, (not on purpose, sad) but because it simply punches hostile mobs within a certain radius millions of times, that mob will die in a shower of black hearts. Because it vaporizes arrows, it's probably good for rushing Pillager towers. (hint; it is). It will steal one shard for every three seconds from your inventory, so mining ore early is essential.

I tested it on (sorry snow golums) certain non-hostile mobs which I spawned in the village. And, (sorry villagers) it goes through walls. Have fun but don't touch golums. Lucky for me I was in creative.
